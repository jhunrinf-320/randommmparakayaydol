
# 🌷 Rose & Tulip Bouquet

A cute and romantic interactive website featuring animated roses, tulips, floating hearts, and a personalized love letter.

## ✨ Features

- 🎁 Animated surprise gift box opening
- 🌹 Animated rose bouquet
- 🌷 Animated tulips
- 💗 Floating hearts and falling flower petals
- 💌 Interactive envelope with a love letter
- 🎵 Original background melody
- ✿ Interactive flower blooming animation
- 📱 Responsive design for mobile and desktop
- ↺ Replay the surprise animation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Google Fonts

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or additional dependencies are required.

## 🌐 GitHub Pages Deployment

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

Your website will be published at:

`https://YOUR-USERNAME.github.io/rose-tulip-bouquet/`

Replace `YOUR-USERNAME` with your GitHub username.

## 💌 Customization

You can customize the website by editing:

- `index.html` — Change the title and love letter.
- `styles.css` — Change colors, animations, and appearance.
- `script.js` — Modify interactive features and background melody.

## 🎵 Music Information

The background melody is generated using JavaScript and the Web Audio API.

Music starts when the visitor clicks the Play button.

No external audio file is required.
